# Local-first landing prototype

This branch preserves the approved October 7, 2026 landing-page concept as a standalone index.html. It is a vision prototype, not a claim that the current app implements every advertised capability.

The Observe / Explain / Choose / Test example and WebMCP disclosure work locally. App, About and contact links retain their existing destinations. Agent connectivity is explanatory copy, not an implemented WebMCP integration.

Preview index.html with a local static server. The source mock-up's icon placeholders are initialized with pinned Lucide icons. No build step is required.

Deployment: the Firebase workflow triggers only on pushes to main. This prototype branch has not been merged and should not be deployed until reviewed. Before launch, review advertised capability availability, app-link labeling, legal pages and the future practice-demo destination.
